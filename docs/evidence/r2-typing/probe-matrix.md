# R2 probe matrix: erased (`any`) values at use sites

Date 2026-11-25, HEAD a8d52b1, reference `siyoc` 0.9.0 at SiyoCompiler 02c2262
(OpenJDK 21.0.12.1), SiyoLLVM `target/siyollvm-0.1.0-SNAPSHOT.jar` built from
6a889ec (no compiler change since).

## How the probes were run

- `probes/generic/<construct>__{ok,wrong,null}.siyo`: generated by
  `probes/tools/gen.py` and `gen2.py`. Each declares `fn probe(a: any)` and
  calls it with a value of the right type (`ok`), of another type (`wrong`) and
  `null`. A function parameter is used so the binder cannot know the value's
  type from its initialiser. Shared prelude: `struct Point { x: int, y: int }`
  with `impl Point { fn sum(self) -> int }`, and `takeS(s: string)`,
  `takeI(n: int)`, `takeL(n: long)`.
- `probes/app/`: the application shapes. `xmod_*`: `imut f = csv.cols(line)`
  where `csv.cols` returns `string[]` from another module, then
  `parseInt(f[1])`, `f[0] < s`, `f[2] + "x"`, `len(f[3])`. `mapfield_*`:
  `imut accounts = book.accounts; imut a: Account = accounts[k]` then
  `a.count += 1`, `a.net = a.net + amt`, `a.count + 1`, `a.show()`; `__null`
  uses a missing key. (A wrong type cannot reach these: the module function
  returns `string[]` and the map is `Map<string, Account>`.)
- `probes/tools/run.py` copies each program to `$TMPDIR`, runs, each through
  `python3 ~/.hermes/automation/siyollvm/bounded.py --` and with `LC_ALL=C`
  from the program's directory, `java -jar
  ~/.cache/siyollvm-oracle/siyoc-02c2262/target/siyo-compiler-0.9.0.jar run
  <file>`, then `bin/siyollvm build <file> -o prog` and, if accepted,
  `./prog`; exit codes are read from each bounded `receipt.json`. Raw
  stdout, first stderr line and exit code of all three are in
  `probes/results.json`. `probes/tools/table.py probes/results.json` prints
  the per-probe table below.

## Task 2 supplementary probes

`probes/task2/`: run on the reference and on SiyoLLVM after Task 2, each
through `bounded.py` (`*.oracle-stdout`, `*.siyollvm-stdout`, first stderr
lines). `extra.siyo` establishes the uniform JVM paths the matrix did not
probe: `%`, `<=`, `>=` with an int beside an any, `>`, `<=`, `%` with a long,
and `endsWith`, `replace`, `toLower`, `ord` of an any (all run; wrong types
raise the same ClassCastException). `toInt(a)` binds as `toInt(float)` and
fails with `VerifyError` (d2i), so it stays rejected. `edge.siyo` checks
evaluation order (each side is unboxed right after it is evaluated), `len`
and `for` over an any holding a struct, and the null-field NPE `because the
return value of "java.util.Map.get(Object)" is null`. Both match byte for
byte, stdout and first stderr line.
