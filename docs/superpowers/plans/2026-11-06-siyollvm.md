# SiyoLLVM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone Siyo → textual LLVM IR → native compiler for a documented scalar/control-flow/function/printing subset.

**Architecture:** Verbatim minimal frontend snapshot (pinned SiyoCompiler 0.9.0) as a second source root; new `siyollvm.*` packages for frontend driver, whitelist validator, IR emitter, clang toolchain and CLI.

**Tech Stack:** Java 21, Maven 3.9, JUnit 5.10, ASM 9.6 (frontend compile dependency), clang ≥ 15 (19 in CI).

**Spec:** `docs/superpowers/specs/2026-11-06-siyollvm-design.md`

## Global Constraints

- Pinned upstream commit: `02c226298296fb4379f7251a9dfba19b7e887f3d` (SiyoCompiler v0.9.0). Snapshot files are never edited by hand.
- Do not add or invent licence terms; attribute authorship (Siyabend Ürün) in PROVENANCE.md.
- No sibling-checkout or network source dependency at build time.
- Diagnostic text for subset violations: `[llvm] <construct> is not supported by SiyoLLVM`.
- Default `mvn verify` must not need clang; `-Pnative` must fail (not skip) without clang ≥ 15.
- clang lookup order: `--clang`, `$SIYOLLVM_CLANG`, `clang` on `PATH`.
- Test temp files: surefire sets `java.io.tmpdir=${project.build.directory}/tmp`.
- TDD red/green logs: `/home/urunsiyabend/.hermes/cache/scratch/siyollvm-supervision/worker-evidence/<task>-{red,green}.log`.
- Supervisor commits; this plan's "commit" steps are replaced by "leave changes staged-free in working tree".

## Review Focus

1. Arithmetic edge cases (`MIN / -1`, `% 0`, long variants, shifts ≥ 32) — native output must equal JVM: Task 5 tests + native corpus `arith_edges`.
2. Deep recursion — must exit 1 with `java.lang.StackOverflowError`, never SIGSEGV: Task 5 `stack_overflow` native case.
3. Unsupported constructs in dead code / uncalled functions — must be rejected: Task 3 validator tests.
4. Non-ASCII identifiers and output under `LC_ALL=C`: Task 4 naming test + Task 7 native `LC_ALL=C` case.
5. Malformed UTF-8 source / missing file / missing clang — clear message, exit 1: Task 6 CLI tests.
